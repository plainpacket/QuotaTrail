## Fixes

- Prevent an in-flight refresh from restoring session data or history after an account is deleted.
- Stop queued refreshes from contacting providers for accounts that have already been removed.
- Recognize rejected Claude OAuth refresh grants and request sign-in instead of repeatedly retrying them as network errors.
- Send enabled limit alerts when a Claude quota window reaches 0% remaining.
- Hide an absent 5-hour limit for weekly-only Codex plans, while preserving real exhausted windows.
- Refresh the ongoing notification after account deletion and remove it when no accounts remain.
- Distinguish queued widget refreshes from work that has actually started.

## Distribution

- Keep the original fonts and include their full SIL Open Font License and copyright notices in the APK, available under Settings → About → Font licenses.
- Run unit tests and lint before a release can be signed and published.
- Clarify browser sign-in, locally collected history, and Android's background refresh constraints.

## Updating

Install this APK over QuotaTrail 1.0.0. The package and signing key are unchanged; uninstalling is
not required. Session expiry or provider-side revocation can still require a fresh sign-in.

QuotaTrail is an unofficial integration. Background refresh timing and lock-screen display depend
on Android settings. This release has automated regression and build verification; long-running
real-account sessions and OEM-specific behavior have not been independently verified on a phone.
